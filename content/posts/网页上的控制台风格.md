### 一、命令行文本
一段“标准的”命令行上的文本由什么构成呢？
首先行首有提示符，然后是文本内容，最后还有光标。
好在css提供了 `animation` 这样的trick,可以在不使用js的情况下实现光标的闪烁。

于是我们自然地给提示符增加风格化，给光标加上闪烁效果。

```css
/* static/style.css */
.prompt {
  color: var(--scard);
  font-weight: bold;
}
.cursor::after {
  content: '▊';
  color: var(--scard);
  animation: blink 1s step-end infinite;
}
@keyframes blink { 50% { opacity: 0; } }
```
 `step-end` 会覆盖默认的 `ease` （类似于呼吸灯渐变变化效果）

于是我们得到了一个还挺像那么回事的命令行文本:

```html
<span class="prompt">$</span> echo "All tragedy erased."<span class="cursor"></span>
```
 另外，网页左侧的状态灯也是同一种实现。
```css
.side-status .dot {
  display: inline-block;
  width: 8px; height: 8px;
  border-radius: 50%;
  background: var(--scard);
  animation: blink 1.6s step-end infinite;
}
```
inline-block保证了inline（雾）

### 二、终端窗口效果
还实现了macOS风格窗口的效果：

```html
<-- index.html -->
<div class="term">
  <div class="term-bar">
    <span class="dot r"></span><span class="dot y"></span><span class="dot g"></span>
    <span class="term-title">~ $ cat now.txt</span>
  </div>
  <div class="term-body">
    <span class="prompt">$</span> <br>
    <span class="prompt">$</span> <span id="type"></span><span class="cursor"></span>
  </div>
</div>
```

```css
/* style.css */
.term {
  background: var(--card);
  border: 1px solid var(--line);
  border-radius: 10px;
  overflow: hidden;
}
.term-bar {
  display: flex;
  align-items: center;
  gap: 8px;
  padding: 8px 14px;
  background: var(--bg);
  border-bottom: 1px solid var(--line);
  font-size: 0.78rem;
  color: var(--dim);
}
.dot { width: 10px; height: 10px; border-radius: 50%; }
.dot.r { background: #ff5f57; }
.dot.y { background: #febc2e; }
.dot.g { background: #28c840; }
.term-title { margin-left: 8px; }
.term-body { padding: 14px 18px; font-size: 0.85rem; }
```
使用了圆角边框和圆角裁切， `flex` 和 `center` 保证了子元素单行排列和垂直居中，gap代替了每个子元素的margin-left，还有不同背景色和更小的字号做层次区分。

这里实际上还出现了 `.dot` 的复用(圆形状态灯)。但 `.side-status .dot` 是两级选择器,比单级的 `.dot` 优先级更高,所以状态灯可以正常显示。而到这里只是因为写在后面而胜出。


### 三、打字机效果
很可惜这样的效果不能仅由css实现，好在js的实现并不困难。
这里选择了文本直接由js保留（或许用 `textContent` 读更好？）
```js
// script.js
const typeEl = document.getElementById('type');
const text = '如你所见，还在学前端，未来还有什么呢...';
let i = 0;
(function type() {
  typeEl.textContent = text.slice(0, ++i);
  if (i < text.length) setTimeout(type, 110);
})();
```

ai还指出：如果选择器没有找到，那么 `typeEl.textContent` 会抛 `TypeError` —— 还会导致后面的所有js全部不执行。
并给出了这样的建议：
```js
if (!typeEl) return;
```
健壮性这一块
