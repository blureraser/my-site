非常好的水题，使我的题解旋转。

数据范围 $1 \le n \le 30$，方阵内只有一个闭合圈，圈内至少有一个 0。

n 太小了，直接 $O(n^2)$ 暴力。

唯一要注意的是这一点：
最容易想到的是"对每个 0 单独判断它能不能走到边界"，这样为了保证效率（每个格子只被访问一次），就要维护全局已访问和本次已访问和一堆 bool 量一堆if，写起来也非常麻烦。

于是我们考虑正难则反：找出所有和边界联通的0，剩下的0就是被围起来的0。

这样每个格子最多被访问一次，总复杂度 $O(n^2)$。还可以背诵找联通块的模板，轻松愉快。
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int n;
vector<int> dx = {0, 0, 1, -1};
vector<int> dy = {1, -1, 0, 0};

void dfs(int i, int j, vector<vector<int>> &map, vector<char> &t) {
    if(t[i * n + j]) return;
    if(map[i][j] == 1) return;
    t[i * n + j] = 1;
    for(int k = 0; k <= 3; k++) {
        int x = j + dx[k];int y = i + dy[k];
        if( x >= 0 && x < n && y >= 0 && y < n) {
            dfs(y, x, map, t);
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    vector<vector<int>> map(n, vector<int>(n, 0));
    for(int i = 0; i < n; i++) {
        for(int j = 0; j < n; j++) {
            cin >> map[i][j];
        }
    }
    vector<char> t(n * n, 0);
    for(int i = 0; i < n; i++) {
        dfs(i, 0, map, t);
        dfs(i, n - 1, map, t);
        dfs(0, i, map, t);
        dfs(n - 1, i, map, t);
    }

    for(int i = 0; i < n; i++) {
        for(int j = 0; j < n; j++) {
            if(!t[i * n + j] && map[i][j] == 0) cout << 2 << " ";
            else cout << map[i][j] << " ";
        }
        cout << "\n";
    }

    return 0;
}

```
一开始写的时候dfs内for循环index使用了i，遮蔽了形参的i。

这个故事告诉我们~~要认真看编译器警告~~形参不要叫i / j。
