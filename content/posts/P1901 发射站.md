纯纯模板题，甚至贴心地标注了int不溢出。

单调栈不赘述，是“求序列每一个元素的最近更大（小）值”的最优解。

乍一看可能觉得算法复杂度为$O(n^2)$，因为单次最坏$O(n)$，共n次，实际上并不是，算法的复杂度为$O(n)$。

一个简单的想法是对于栈本身，每个元素最多进一次出一次，所以是线性的。

这种单次最坏$O(n)$总复杂度$O(n)$似乎也被称为 **均摊$O(n)$**，以示对依赖概率的 **平均$O(n)$** 的区分。

```cpp
#include <algorithm>
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<int> h(n, 0);
    vector<int> v(n, 0);
    for(int i = 0; i < n; i++) cin >> h[i] >> v[i];

    vector<int> sum(n, 0);
    stack<int> l;
    for(int i = 0; i < n; i++) {
        while(!l.empty()) {
            if(h[i] > h[l.top()]) l.pop();
            else break;
        }
        if(!l.empty()) sum[l.top()] += v[i];
        l.push(i);
    }
    stack<int> r;
    for(int i = n - 1; i >= 0; i--) {
        while(!r.empty()) {
            if(h[i] > h[r.top()]) r.pop();
            else break;
        }
        if(!r.empty()) sum[r.top()] += v[i];
        r.push(i);
    }
    cout << *max_element(sum.begin(), sum.end());

    return 0;
}
```
