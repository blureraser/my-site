树状 DP，顾名思义，是树上的 DP。

有简单的模式可循，总是会令：
> `dp[i][j]`… 为“以i为根节点的子树中（在...条件下）的最优结果”。

比如P1352：
每个人只有且只有一个直接上司（除了校长没有），所以上司关系可以抽象为树。令 `dp[i][0/1]` 为“在（不）选择i的条件下，以i为根节点的子树中的最大快乐值”。
同时对每一个父节点u， `dp[u][1]` （直接上司到场，所有子都不会到场）是遍历所有子节点 v 的 `dp[v][0]` 之和； `dp[u][0]` （直接上司不到场，子可以选择到场或不到场）是遍历所有子节点 v 的 `max(dp[v][1], dp[v][0])` 之和。

然后通过迭代dfs的顺序保证每一个子都先得到结果再计算对父的贡献，就可以了：
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

vector<vector<int>> g;
vector<int> r;
vector<vector<int>> dp;

void dfs(int u) {
    if(g[u].empty()) {
        dp[u][1] = r[u];
        return;
    }
    dp[u][1] = r[u];
    for(int v : g[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][1], dp[v][0]);
        dp[u][1] += dp[v][0];
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    g.assign(n + 1, {});
    r.assign(n + 1, 0);
    dp.assign(n + 1, {0, 0});
    vector<char> hasFa(n + 1, 0);
    for(int i = 1; i <= n; i++) {
        cin >> r[i];
    }
    for(int i = 1; i <= n - 1; i++) {
        int u; int v;
        cin >> v >> u;
        g[u].push_back(v);
        hasFa[v] = 1;
    }
    int fa = 1;
    for(int i = 1; i <= n; i++) {
        if(!hasFa[i]) {
            fa = i;
            break;
        }
    }
    dfs(fa);
    cout << max(dp[fa][0], dp[fa][1]);

    return 0;
}
```
是很标准的树状 DP 。

---

有很标准的就会有不那么标准的，比如 P2014：

每节课最多只有一个先导，所以可以抽象为森林，引入虚的根0可以变成单个树。

主要的问题在于对只能选k节课的约束的处理，这样的“代价”的引入在 DP 的语境下让人不得不联想到0/1背包：所以选择了 dp 的第二个状态j为已选择的课程数，这样，正像0/1背包一样，在计算父节点dp时也会依赖于j更小的父节点dp，所以需要倒序遍历更新，总是先更新一个节点中j更大的dp。

选取bfs是刚上手时觉得bfs维护的队列中的元素正是“可选取的下一节课”，直观上符合顺序要求。但其实直接dfs是可以的。（实际上，考虑到遍历儿子的操作，dfs应当更优雅）。
```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    vector<int> ps(n + 1, 0);
    vector<vector<int>> g(n + 1);
    vector<vector<int>> dp(n + 1, vector<int>(m + 2));
    for (int i = 1; i <= n; i++) {
        int temp; cin >> temp;
        g[temp].push_back(i);
        cin >> ps[i];
    }

    vector<int> order;
    queue<int> q; q.push(0);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : g[u]) q.push(v);
    }

    for (int i = (int)order.size() - 1; i >= 0; i--) {
        int u = order[i];
        dp[u][0] = 0;
        dp[u][1] = ps[u];
        for (int j = 2; j <= m + 1; j++) dp[u][j] = 0;

        for (int v : g[u]) {
            for (int j = m + 1; j >= 1; j--)
                for (int k = 0; k <= j - 1; k++)
                    dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
        }
    }

    cout << dp[0][m + 1];
    

    return 0;
}
```
